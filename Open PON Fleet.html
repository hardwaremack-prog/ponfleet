Looking for PON Fleet...

PON Fleet is the control server for all your PON Lab Pis, so it has to be started first.

  1. Double-click the PON Fleet icon on the Desktop (added by Set Up My Apps.sh), or run bash start-fleet.sh in this folder.
  2. On Windows, double-click Start PON Fleet.bat in this folder.
  3. To keep it running all the time on a Pi: sudo ./install.sh in this folder.
